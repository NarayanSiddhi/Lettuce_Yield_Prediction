## Python example (XGBoost)

```python
import pandas as pd
from xgboost import XGBRegressor
from sklearn.model_selection import LeaveOneOut
from sklearn.metrics import mean_absolute_error

df = pd.read_csv("ml/checkpoint_trial1_compact.csv")
target = "target_median_fw_g"
drop = {"sample_id", "trial", "day", "date", "window_start", "window_end",
        "label_source", target}
X = df.drop(columns=[c for c in drop if c in df.columns])
y = df[target]
X = X.apply(pd.to_numeric, errors="coerce").fillna(X.median())

loo = LeaveOneOut()
preds = []
for tr, te in loo.split(X):
    m = XGBRegressor(n_estimators=80, max_depth=3, learning_rate=0.1, random_state=42)
    m.fit(X.iloc[tr], y.iloc[tr])
    preds.append(m.predict(X.iloc[te])[0])
print("LOO MAE:", mean_absolute_error(y, preds))
```

## Python example (Random Forest)

```python
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline

df = pd.read_csv("ml/checkpoint_trial1_image.csv")
y = df["target_median_fw_g"]
X = df.drop(columns=[c for c in df.columns if c in {
    "sample_id", "trial", "day", "date", "window_start", "window_end",
    "label_source", "target_median_fw_g",
}], errors="ignore")

pipe = Pipeline([
    ("impute", SimpleImputer(strategy="median")),
    ("rf", RandomForestRegressor(n_estimators=200, max_depth=4, random_state=42)),
])
# Use leave-one-out or train on all 8 only for exploration
pipe.fit(X, y)
```

## Notes

- **8 labeled checkpoints** per trial → use strong regularization; LOO or time-based splits only.
- **`window_days_count`**: prefer rows with value 4 when timelapse + cups cover the full 4-day window.
- **Trial 2**: `label_source` in CSV warns that FW targets are shifted from trial 1’s protocol unless you update the tracker.
